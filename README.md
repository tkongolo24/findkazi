# findkazi

A phone-first practice tool (Kinyarwanda + English) that helps young people in Rwanda learn to apply for jobs online: build a CV, write a job email, and fill in an online application. Includes a facilitator page for user-testing sessions.

Plain HTML, CSS and JavaScript — no build step. Open `index.html` in a browser, or serve the folder with any static host (e.g. Cloudflare Pages, output directory `/`).

Made by IGFT Group 5.
